# DU-cluster

The Dark Username Company — AI Business Operating System.

Standalone international, English-first control plane for digital products.

Core loop: Global trends -> opportunity scoring -> Product Factory -> Content Factory -> QA -> publishing -> Shopify sales -> analytics -> optimization.

Market: International / English-first. Algeria is not a viral/trend criterion. Focus: AI, technology, Linux, cybersecurity, automation, software, SaaS, creator tools, productivity and digital products.

Runtime: Python 3.11+, FastAPI, SQLite development persistence, Docker. Production is prepared for PostgreSQL and Redis/queue.

Command center: run the API and open /web/index.html. The dashboard exposes health, market, language, agent count and an execution console.

API: /health, /ready, /api/v1/ops/status, /api/v1/agent/status, /api/v1/dashboard, /api/v1/trends/analyze, /api/v1/trends/ingest, /api/v1/trends/recent, /api/v1/opportunities/evaluate, /api/v1/products/generate, /api/v1/content/generate, /api/v1/pipeline/run, /api/v1/agent/execute, /api/v1/agent/runs, /api/v1/integrations/status, /api/v1/memory/{namespace}, /docs.

Integrations: Metricool, Shopify and Canva are represented by secure integration contracts. External actions are only marked complete after provider confirmation.

Production: use docker-compose.prod.yml, a secret manager, HTTPS, PostgreSQL, Redis/queue, backups, monitoring and authenticated access.

Business objective: $1,000,000/month is a long-term business objective, not a guarantee.

Truthfulness and safety: DU-cluster does not fabricate trend metrics, sales, publishing results or provider actions. It does not manufacture engagement or use deceptive clickbait. Cybersecurity workflows must remain defensive and authorized.
