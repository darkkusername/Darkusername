# DU-cluster v2

## Mission
Operate The Dark Username Company as an AI-first digital-products business system.

## Market policy
- International market.
- English is the primary operating/content language.
- Algeria is not a trend criterion or geographic optimization target.
- Local-only signals are excluded unless they have clear international relevance.
- Focus: AI, technology, Linux, cybersecurity, automation, software, SaaS, creator tools, productivity and digital products.

## Agent graph
TrendScout -> OpportunityAnalyzer -> ProductStrategist -> ProductBuilder -> ContentStrategist -> ContentProducer -> QA -> Publisher -> AnalyticsAgent -> Optimizer.

## Commercial loop
Traffic -> Leads -> Conversion -> AOV -> Repeat Purchase.

## Integrations
Metricool, Shopify and Canva are external integrations. They require valid credentials and API responses before DU-cluster reports an action as completed.

## Safety
- No fake engagement.
- No spam.
- No deceptive claims.
- Cybersecurity automation is defensive/authorized.
- Financial projections are clearly labeled as projections.
- Publication can be configured with approval gates.

## Deployment
Run locally with Docker Compose. Production deployment requires a hosted environment, secrets, domains and valid third-party credentials.
