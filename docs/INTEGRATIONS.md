# DU-cluster integrations

Metricool: connected brand is currently reported as darkkuser, with Instagram, TikTok and YouTube network connections. Provider responses are the source of truth.

Shopify: external sales integration. Use OAuth/API credentials from environment variables or a secret manager. Never commit credentials.

Canva: design-production integration. Assets are considered complete only after provider confirmation.

Publishing defaults to preview/review. Autonomous publishing is explicit configuration and must validate the provider response.
